# 部署說明（Apache ＋ 連線轉傳伺服器）

架構：

```
玩家瀏覽器 ──http://對外網址:7777/volleyball/──▶ 路由器 7777 → 這台 Apache 8081
                                                   ├─ /volleyball/      → htdocs/volleyball（打包好的遊戲頁面，Alias）
                                                   └─ /volleyball/lan   → 127.0.0.1:8090（Node 轉傳伺服器，ProxyPass）
```

- 單人、練習、教學只需要 Apache。
- 多人連線另外需要 Node 轉傳伺服器（`server/lan.js`）在這台電腦上跑著；它只聽本機 127.0.0.1:8090，不用對外開埠號。
- 遊戲會連到「網頁所在路徑」底下的 `lan`（`/volleyball/` → `/volleyball/lan`），改放其他子資料夾時 ProxyPass 的路徑跟著改就好。

## 1. 更新遊戲頁面

```
npm run build
```

把 `dist/` 裡面的檔案複製到 `D:/Apache2_4_65/htdocs/volleyball/`（跟以前一樣）。

## 2. Apache 開啟轉送模組（只要做一次）

`D:/Apache2_4_65/conf/httpd.conf`，把這兩行前面的 `#` 拿掉：

```apache
LoadModule proxy_module modules/mod_proxy.so
LoadModule proxy_http_module modules/mod_proxy_http.so
```

（Apache 2.4.47 以後 `mod_proxy_http` 就能轉送 WebSocket，不需要 `mod_proxy_wstunnel`。之後「情況 A」的 ProxyPass 也是用這兩個模組。）

## 3. vhost 加一行 ProxyPass

在 `<VirtualHost *:8081>` 裡面、`Alias /volleyball` 那段旁邊加上：

```apache
    # 排球遊戲的連線對戰：/volleyball/lan 轉給本機的 Node 轉傳伺服器（啟動連線伺服器.bat，埠號 8090）
    ProxyPass /volleyball/lan http://127.0.0.1:8090/lan upgrade=websocket
```

- ProxyPass 會比 Alias 先處理，所以 `/volleyball/lan` 會轉給 Node，其他 `/volleyball/...` 照樣走 Alias。
- 不需要 ProxyPassReverse（WebSocket 不會轉址）。
- 轉傳伺服器每 20 秒 ping 一次，等對手時也不會被 Apache 的逾時（預設 60 秒）切斷，不用改 Timeout。

改完先檢查語法，再重新啟動 Apache：

```
D:\Apache2_4_65\bin\httpd.exe -t
```

出現 `Syntax OK` 再重啟 Apache 服務。

## 4. 啟動連線轉傳伺服器

在專案的 `排球遊戲` 資料夾（有 `server/` 和 `node_modules/` 的那個，不是 htdocs）雙擊 `啟動連線伺服器.bat`。

- 視窗開著就是在跑，關掉就停止（正在進行的連線對戰會中斷）。
- 第一次執行如果沒有 `node_modules`，會自動安裝套件。
- 想開機自動啟動：按 Win＋R 輸入 `shell:startup`，把 bat 的捷徑放進去。

## 5. 開始對戰

兩位玩家都用平常的遊戲網址開（外網：`http://對外網址:7777/volleyball/`），主畫面「多人連線」→ 一台「建立房間」、另一台「加入房間」。

- 開房畫面會顯示要分享的網址：用對外網址開的，顯示的就是同一個網址；用 `localhost` 開的，會換成這台電腦的內網位址（同一個網路的人能用，外網的人要開對外網址）。
- 出現「連不上連線伺服器」：bat 沒在跑，或 Apache 沒加 ProxyPass／沒開模組。

## 之後有多個遊戲時的規劃

每個遊戲一個子路徑：頁面用 Alias，需要即時連線的遊戲自己跑一個 Node 轉傳伺服器、各用一個本機埠號，用 ProxyPass 轉過去。對外永遠只有 Apache 一個埠號。

| 遊戲 | 頁面 | 連線路徑 | 本機埠號 |
| --- | --- | --- | --- |
| 排球 | `/volleyball/` | `/volleyball/lan` | 8090 |
| （下一個遊戲） | `/xxx/` | `/xxx/lan` | 8091 |

埠號記在這張表和 vhost 的註解裡，避免撞號。

## 沒有 Apache 時

`npm run lan`：先打包，再由 Node 同時提供頁面和轉傳，玩家開 `http://主機IP:8090`（只適合同一個內網，第一次會跳 Windows 防火牆詢問）。

## 開發模式測連線

開兩個終端機：`npm run lan:server`（轉傳伺服器）和 `npm run dev`（Vite 會把 `/lan` 轉給 8090），兩個瀏覽器分頁開 Vite 的網址就能測。
