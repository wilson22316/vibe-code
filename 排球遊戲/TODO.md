# 3D 排球遊戲 — 待辦清單

## 已確定的規格

- 形式：2v2 沙灘排球
- 操作：鍵盤（簡化版：角色自動跑位，玩家專心抓擊球時機）
- 模式：單人對 AI（多人改為內網連線，延後）
- 技術：Vite + Three.js + 原生 JavaScript，球的物理自己寫簡化拋物線
- 風格：Q 版低多邊形角色、陽光沙灘，休閒運動遊戲風（原創設計）

- [x] 2-4. 扣球落點選擇＋能量條＋強力擊球（使用者提出）
  - 已確定的設計：
    - 按鍵：方向只用方向鍵（A/D 不再當左右），A 鍵專門開強力擊球
    - 持續：開啟後只作用在下一次扣球，用完能量歸零
    - 累積（預設，可再調）：每次扣球 +1、Perfect 扣球 +2，滿格 5 點
    - AI：簡單不用；普通偶爾用；困難會抓時機用
    - 防守：強力球還是接得起來，但接球判定時窗更窄、攔網範圍變小
  - [x] 扣球時用上下左右選落點：左右選邊、上＝深球、下＝短球（共 9 區），扣球前顯示瞄準準星；預設斜線中間深度
  - [x] 能量條：介面顯示雙方能量（滿了提示按 A、對手滿了也會提醒）
  - [x] 能量滿時按 A 開啟強力擊球：球速快 30%、較難接也較難攔、鏡頭震動更大
    - 實測：「好球保證過網」會把太平的球放慢，短球和中間深度（預設瞄準）幾乎跟一般扣球一樣快，只有深球明顯變快（見「之後再做」）
  - [x] 強力擊球特效：球外層包一層能量光、金色拖尾、專屬音效、POWER! 跳字
  - [x] 一般扣球也加上球的拖尾（白色）
  - [x] 蓄氣氣場（使用者提出）：按 A 後兩人先冒小氣場，確定誰扣球時那人全開、隊友散掉；金色火焰外殼＋腳下光圈＋往上飄的光點＋蓄氣低音；AI 開啟時也有（當作警告）
  - [x] 衝擊定格（使用者提出，只有玩家的強力扣球）：鏡頭直接切到扣球者特寫、定格（POWER.freezeTime，預設 0.5 秒）、白光＋速度線＋衝擊波，之後拉回原本視角（POWER.cutBackTime）再接慢動作
  - [x] 擊球時手碰到球（使用者提出）：碰球前 0.3 秒手伸向球（Q 版手短，差一點時手臂卡通式伸縮），扣球／發球的手掌、舉球的雙手、墊球的前臂剛好貼在球上；碰球後的順勢動作從碰球那一刻的姿勢接下去
    - 起跳高度依觸球高度計算（強力扣球不再另外超級跳）；站位依擊球種類調整（HIT.standBehind），球在額頭前上方／胸前，不會貼到臉
    - 強力扣球定格那一幀停在手碰球的那一刻（定格後物理先不往下算）
    - 發球改成拋球 → 起跳 → 擊球（約 0.35 秒）；攔網起跳 1.2 公尺、雙手高舉
    - 已知限制：球員沒完全跑到位就擊球時（例如救遠球），手可能還差幾公分
  - [x] 每局開局玩家就有一次滿能量（POWER.startEnergy）
  - [x] 再按一次 A 取消強力擊球（能量保留）
  - [x] 氣場全開加強 50%（POWER.auraFull = 1.5）：內外兩層火焰、火舌往上竄、一般混合讓火在藍天上也是橘紅色

- [x] 2-9. 練習模式
  - [x] 不計分，可選練習項目：發球／接球／扣球／攔網
    - 發球：對手不接，看球落在哪（落在對方場內算成功）
    - 接球：對手發球（不會失誤），墊起來就算成功（Bad 不算）
    - 扣球：隊友舉球過來，選落點扣下去；對手不接也不攔，落在對方場內算成功；強力擊球隨時可用
    - 攔網：對手舉球、直線扣球（時機抓對就攔得到；Bad 或太晚攔不到），攔下來算成功
    - 畫面上方顯示「成功 N / 共 M」，底部提示換成該項目的操作說明
  - [x] 提示圈放慢、可無限重來
    - 速度選項：慢速（預設，整個遊戲 0.6 倍速，時機判定等於變寬）／正常
    - 每球判定完 1.2 秒自動換下一球；Esc 暫停可重新開始（次數歸零）或回到練習選單換項目
- [x] 2-10. 操作教學

    - 上下鍵或滑鼠滾輪捲動
  - [x] 互動教學關卡：發球 → 接球 → 扣球 → 攔網，做對才進下一步
    - 用練習模式的項目（固定慢速），左上角說明卡告訴玩家這一步要做什麼；成功一次就進下一步，失敗就重來
    - 四步都完成：彩帶慶祝，3 秒後回主畫面；暫停選單可重來這一步或回到教學選單
