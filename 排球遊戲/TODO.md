# 3D 排球遊戲 — 待辦清單

## 已確定的規格

- 形式：2v2 沙灘排球
- 操作：鍵盤（簡化版：角色自動跑位，玩家專心抓擊球時機）
- 模式：單人對 AI（多人改為內網連線，延後）
- 技術：Vite + Three.js + 原生 JavaScript，球的物理自己寫簡化拋物線
- 風格：Q 版低多邊形角色、陽光沙灘，休閒運動遊戲風（原創設計）

## 第二輪：人物與畫面優化

已確定：人物用程式建模精修（不用外部模型）、畫風走卡通描邊（像動畫角色）、要做角色自訂。

- [x] 2-1. 卡通渲染風格

- [ ] 2-4. 扣球落點選擇＋能量條＋強力擊球（使用者提出）
  - 已確定的設計：
    - 按鍵：方向只用方向鍵（A/D 不再當左右），A 鍵專門開強力擊球
    - 持續：開啟後只作用在下一次扣球，用完能量歸零
    - 累積（預設，可再調）：每次扣球 +1、Perfect 扣球 +2，滿格 5 點
    - AI：簡單不用；普通偶爾用；困難會抓時機用
    - 防守：強力球還是接得起來，但接球判定時窗更窄、攔網範圍變小
  - [ ] 扣球時用上下左右選落點：左右選邊、上＝深球、下＝短球（共 9 區），扣球前顯示瞄準標記
  - [ ] 能量條：介面顯示雙方能量
  - [ ] 能量滿時按 A 開啟強力擊球：球速更快、更用力、鏡頭震動更大
  - [ ] 強力擊球特效：球外層包一層能量光、拖尾
  - [ ] 一般扣球也加上球的拖尾
