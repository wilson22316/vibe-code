# 3D 排球遊戲 — 待辦清單

## 已確定的規格

- 形式：2v2 沙灘排球
- 操作：鍵盤（簡化版：角色自動跑位，玩家專心抓擊球時機）
- 模式：單人對 AI ＋ 本機雙人（同一鍵盤）
- 技術：Vite + Three.js + 原生 JavaScript，球的物理自己寫簡化拋物線
- 風格：Q 版低多邊形角色、陽光沙灘，休閒運動遊戲風（原創設計）

- [x] 1. 場景與鏡頭：沙灘、球網、場地線、燈光

- [x] 3. 角色與移動：Q 版角色、自動跑位到落點
- [x] 4. 擊球系統：發球／接球／舉球／扣球／攔網 ＋ 時機判定（Perfect / Good / Miss）
  - [x] 4a. 接球／舉球／扣球、時機判定與提示圈、對手自動回擊、得分判定
  - [x] 4b. 攔網

- [x] 6. AI 對手：簡單／普通／困難（數值以模擬調整，待實際試玩再微調）
