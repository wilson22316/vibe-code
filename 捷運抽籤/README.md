# 台北捷運隨機抽籤系統

一個互動式的台北捷運站隨機抽籤系統，一次抽取完整的捷運站資訊。

## 功能特色

### 🎯 一鍵抽籤
- **完整捷運站**：一次抽取包含站號、站名和路線名稱的完整資訊
- **隨機選擇**：從所有台北捷運站中隨機選擇一站
- **即時顯示**：抽籤過程中即時顯示站號和站名

### 🎨 視覺效果
- 現代化的漸層背景設計
- 抽籤動畫效果
- 響應式設計，支援手機和電腦
- 路線顏色對應實際捷運路線色彩

### 📊 歷史記錄
- 自動保存抽籤歷史
- 顯示抽籤時間
- 最多保存10筆記錄

### ⌨️ 快捷鍵
- `空白鍵`：抽取捷運站
- `R` 鍵：重新開始
- `C` 鍵：清除歷史記錄

## 使用方法

1. **開啟系統**：在瀏覽器中開啟 `index.html`
2. **抽取捷運站**：點擊「抽取捷運站」按鈕或按空白鍵
3. **查看結果**：系統會顯示完整的站號、站名和路線名稱
4. **重新開始**：點擊「重新開始」按鈕或按 `R` 鍵
5. **清除歷史**：點擊「清除歷史」按鈕或按 `C` 鍵

## 技術特色

- **純前端實現**：無需後端伺服器
- **本地儲存**：使用 localStorage 保存歷史記錄
- **響應式設計**：支援各種螢幕尺寸
- **動畫效果**：抽籤過程有視覺回饋
- **無障礙設計**：支援鍵盤操作

## 自訂設定

### 修改路線資料
在 `script.js` 中的 `mrtLines` 物件可以修改路線資料：

```javascript
const mrtLines = {
    'BL': { name: '板南線', color: '#0070BD', maxStations: 23 },
    // 新增或修改路線...
};
```

### 調整動畫速度
修改 `script.js` 中的動畫間隔時間：

```javascript
// 預設為 100ms，可以調整為更快或更慢
}, 100);
```

### 修改歷史記錄數量
在 `addToHistory` 函數中修改：

```javascript
// 預設為10筆，可以調整
if (drawHistory.length > 10) {
    drawHistory = drawHistory.slice(0, 10);
}
```
