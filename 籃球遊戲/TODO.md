## 2. 第一批動作
依編號順序做。每項：改 `athlete_anims.py` → 重產模型 → 量手與球、腳底、移動時腳滑 → 展示館截圖檢查 → commit。

1. [x] 無球待機：沿用現有的 Idle
2. [x] 持球待機（三威脅）`TripleThreat`：48 格循環，雙手持球在右腰前，屈膝前傾
3. [x] 運球走 `DribbleWalk`：循環，右手運球、原地走，遊戲以固定速度推動
4. [x] 慢跑 `Jog`：循環，無球，原地
5. [x] 無球衝刺 `Run`：循環，無球，原地
6. [x] 急停 `StopJump`：單次，運球衝刺中收球雙腳急停，結束在三威脅姿勢
7. [x] 定點投籃 `SetShot`：單次，雙腳不離地出手
8. [x] 上籃 `Layup`：單次，兩步上籃、右手出手
    - [x] 改成低手上籃：雙手夾球 → 左手放開、右手轉到球下方掌心朝上 → 托出去（左手往側邊張開）→ 放下同 Idle；收球時球往前移，不再陷進肚子
