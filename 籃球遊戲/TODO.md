# 待辦清單

完成一項就把 `[ ]` 改成 `[x]`。大方向見 [CLAUDE.md](CLAUDE.md) 的路線圖，這裡記細項。
第 1 階段依編號順序做；第 2 階段之後輪到時再排順序。

## 1. 動作展示館

### 專案建立
1. [x] 加 `.gitignore`（`node_modules/`、`dist/`、`blender/out/`、`__pycache__/`）
2. [ ] 用 Vite 建立 Vue 3 專案、安裝 three.js
3. [ ] 核對安裝的 three.js 版本與 `reference/` 舊寫法的差異
4. [ ] 更新 README 的開發指令（拿掉「預定」）

### 先讓角色動起來
5. [ ] 基本場景：相機、地面、燈光（半球光＋帶陰影的平行光，重新調強度）
6. [ ] 載入 `athlete_game.glb`，播放 Idle
7. [ ] 360 度旋轉視角（之後每一步都靠它檢查）

### 展示館功能
8. [ ] 動作清單，點選播放（Idle、Dribble、Shoot、Sprint）
9. [ ] 速度調整
10. [ ] 顯示／隱藏骨架
11. [ ] 顯示／隱藏地面格線

### 手繪動畫風外觀
12. [ ] 卡通材質（`MeshToonMaterial`，4 階色階）
13. [ ] 描邊（背面放大法；骨架網格用 `SkinnedMesh` 綁同一副骨架）
14. [ ] 背景（藍天白雲與草地）

### 檢查與串接測試
15. [ ] 逐一檢查 4 個動作，記錄問題
16. [ ] 動作切換的淡入淡出
17. [ ] 切換時球正確出現或消失
18. [ ] Shoot 第 18 格出手後球消失
